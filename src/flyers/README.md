# Shared flyers

Files in this folder appear on the website's
[Flyers and printables](https://csf-dsa.org/member-resources/printables/#shared)
page under **Shared flyers**. You don't need to touch any code.

## How to add a flyer

1. On this page on GitHub, click **Add file → Upload files**.
2. Drag in your flyer: a **PDF**, or an image (**PNG**, **JPG**, or **WEBP**).
3. At the bottom, pick **Create a new branch for this commit and start a pull request**,
   then click **Propose changes**, then **Create pull request**.
4. A bot comments on the pull request with a link to a preview of the site. Check
   that your flyer looks right.
5. Someone on the steering committee reviews it and clicks **Merge**. A few minutes
   later it's live.

## Naming your file

The file name becomes the title on the website.

- `Pride-picnic.pdf` shows up as **Pride picnic**.
- Start the name with a date to show it and sort newest first:
  `2026-06-14-Pride-picnic.pdf` shows **Pride picnic**, dated June 14, 2026.
- Use letters, numbers, and dashes. Avoid spaces and symbols.

## Optional extras

Give these the **same name** as your flyer, with a different ending:

| Add this                        | And you get                                        |
|---------------------------------|----------------------------------------------------|
| `Pride-picnic.png` (or `.jpg`)  | A picture preview for a PDF flyer. Without one, the site shows a PDF icon. |
| `Pride-picnic.txt`              | A short description under the title. One or two sentences of plain text. |

## Please keep in mind

- Chapter and branch events only. Don't speak for the chapter on positions or
  endorsements it hasn't decided.
- No members' photos, names, or contact details without their say-so.
- Keep files under 10 MB. GitHub won't take uploads over 25 MB.
- To remove a flyer, open it here, click the **⋯** menu, choose **Delete file**, and
  open a pull request the same way.
